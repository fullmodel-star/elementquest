# 元素勇者：週期表大冒險 elementquest

RPG 風格的國中元素週期表學習遊戲，單檔 HTML、可離線、可安裝成 PWA。

## 功能
- 🧭 **全貌總覽**：完整 118 格週期表外形（含鑭系／錒系），依分類上色；56 個教學元素可點開詳情卡，其餘 62 格也能看基本介紹但標示「尚未列入教學範圍」
- 🗺️ **地圖**：9 個「王國」分區（鹼金屬／鹼土金屬／鹵素／鈍氣／非金屬／過渡金屬／合金鍛造／鑭系／放射性），⭐標記 32 個國中會考較常見的元素（2026-08-18 補入 Mn：雙氧水＋二氧化錳製氧為國中經典實驗），且⭐元素在王國試煉出題與合成結晶獎勵中都有實際加權
- 📖 **背誦翻牌**：符號／中文名／emoji／生活應用小知識
- ⚗️ **合成台**：46 個真實化學反應與生活合金配方，支援 2～3 元素合成（水、鐵鏽、黃銅、打火石合金、不鏽鋼、釹鐵硼磁鐵…），配方分普通／稀有／傳說三級，合金與真實化學反應分開標示，附合成圖鑑進度條
- ⚔️ **王國試煉**：5 種題型交錯（辨識／反向辨識／分類／跨元素比較／找碴），跨元素比較題以「化學分類」分組且金屬／過渡金屬視為同組確保答案唯一、取材限已學元素；找碴題的錯誤元素強制「金屬類⇄非金屬類」跨界（或鈍氣）且不得構成另一條真實配方，杜絕「正確方程式被判錯」；0-5 級分級熟練度（類 Leitner box，答錯只降級不歸零），難度自選＋每場勝利固定 +1 結晶、首次破關 +10、勝利結算畫面列出各元素熟練度
- 💎 **結晶經濟**：答題／合成／複習合成都能獲得結晶，戰鬥中可花 3 顆結晶排除兩個錯誤選項（消耗出口）

## 技術
- 純前端單檔 `index.html`，無建置流程，localStorage 存進度
- PWA：`manifest.json` + `sw.js`（離線快取）+ 安裝按鈕（ridgeline-branding skill 注入）
- 品牌識別：學習家族（第納利 Denali，`#4E6A7C`），六色盤主 UI；週期表分類色與王國代表色是功能性例外，非裝飾用品牌色

## 部署
- GitHub Pages：https://fullmodel-star.github.io/elementquest/
- repo：`fullmodel-star/elementquest`（Public，`master` 分支）
- 純靜態，git push 即部署，無 CI

## 設計依據
本作教學範圍（56元素/46配方/5題型/⭐必考標記）是根據國中理化老師、國中生玩家、學習科學教授三方實測意見反覆調整過的版本，細節見 git commit 歷史。2026-08-18 對外發布前完成化學專家逐項內容審查（56卡零事實錯誤、46配方全配平）＋學生視角全功能實測（node 模擬 2000+ 次抽題零錯誤），審修內容見 更新記錄.md。
