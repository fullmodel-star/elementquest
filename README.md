# 元素勇者：週期表大冒險 elementquest

RPG 風格的國中元素週期表學習遊戲，單檔 HTML、可離線、可安裝成 PWA。

## 功能
- 🧭 **全貌總覽**：完整 118 格週期表外形（含鑭系／錒系），依分類上色；56 個教學元素可點開詳情卡，其餘 62 格也能看基本介紹但標示「尚未列入教學範圍」
- 🗺️ **地圖**：8 個「王國」分區（鹼金屬／鹼土金屬／鹵素／鈍氣／非金屬／過渡金屬／鑭系／放射性），⭐標記 31 個國中會考較常見的元素
- 📖 **背誦翻牌**：符號／中文名／emoji／生活應用小知識
- ⚗️ **合成台**：44 個真實化學反應與生活合金配方（水、鐵鏽、硼砂史萊姆、黃銅、打火石合金…）
- ⚔️ **王國試煉**：5 種題型交錯（辨識／反向辨識／分類／跨元素比較／找碴），0-5 級分級熟練度（類 Leitner box，答錯只降級不歸零），難度自選＋稀有結晶變動獎勵

## 技術
- 純前端單檔 `index.html`，無建置流程，localStorage 存進度
- PWA：`manifest.json` + `sw.js`（離線快取）+ 安裝按鈕（ridgeline-branding skill 注入）
- 品牌識別：學習家族（第納利 Denali，`#4E6A7C`），六色盤主 UI；週期表分類色與王國代表色是功能性例外，非裝飾用品牌色

## 部署
- GitHub Pages：https://fullmodel-star.github.io/elementquest/
- repo：`fullmodel-star/elementquest`（Public，`master` 分支）
- 純靜態，git push 即部署，無 CI

## 設計依據
本作教學範圍（56元素/44配方/5題型/⭐必考標記）是根據國中理化老師、國中生玩家、學習科學教授三方實測意見反覆調整過的版本，細節見 git commit 歷史。
