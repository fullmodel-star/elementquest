# 元素勇者：週期表大冒險 elementquest

RPG 風格的國中元素週期表學習遊戲，單檔 HTML、可離線、可安裝成 PWA。

## 功能
- 🧭 **全貌總覽**：完整 118 格週期表外形（含鑭系／錒系），依分類上色；56 個教學元素可點開詳情卡，其餘 62 格也能看基本介紹但標示「尚未列入教學範圍」。三種顯示模式：
  - 🎨 分類
  - 🔤 部首解碼：格子改顯示中文名、依部首上色（金／气／石／水），附探究任務（汞為何用水、類金屬命名兩派）
  - 🌡️ 溫度實驗：-273～5600°C 滑桿＋10 個預設溫度，即時顯示每個元素的固／液／氣態；熔沸點取 PubChem 與 Periodic-Table-JSON 交叉比對一致者，其餘標「資料不足」
- 🔬 **研究室**（不需先選王國）：
  - 🕵️ 元素偵探：13 個案件（焰色反應、氣體檢驗、金屬鑑定…），自選實驗→看觀察結果→推理答案；內建「嚐嚐看」「直接聞」陷阱教實驗安全
  - ⚖️ 配平挑戰：35 題（23 題取自遊戲配方＋12 題課本經典反應，含光合作用、大理石加鹽酸），調係數時即時顯示左右原子數，要求最簡整數比
- 🗺️ **地圖**：9 個「王國」分區（鹼金屬／鹼土金屬／鹵素／鈍氣／非金屬／過渡金屬／合金鍛造／鑭系／放射性），⭐標記 32 個國中會考較常見的元素（2026-08-18 補入 Mn：雙氧水＋二氧化錳製氧為國中經典實驗），且⭐元素在王國試煉出題與合成結晶獎勵中都有實際加權
- 📖 **背誦翻牌**：符號／中文名／emoji／生活應用小知識
- ⚗️ **合成台**：47 個真實化學反應與生活合金配方，支援 2～3 元素合成（水、鐵鏽、黃銅、打火石合金、不鏽鋼、釹鐵硼磁鐵…），配方分普通／稀有／傳說三級，合金與真實化學反應分開標示，附合成圖鑑進度條；還沒合成過的配方材料以 ❓ 隱藏，可花結晶揭露；三元傳說配方（不鏽鋼、複合青銅、釹鐵硼磁鐵）要三種材料在試煉的熟練度都達 2/5 才能合成（二元配方不設門檻；組合對了但還不夠熟時不扣結晶、材料直接記進配方表；合成過的永遠能複習合成）
- ⚔️ **王國試煉**：6 種題型交錯（辨識／反向辨識／分類／跨元素比較／找碴／反向合成），反向合成題給產物名稱、選出要用哪些元素，只出已合成過的化學反應配方（合金現實中常有多種配方，不出；未合成的材料藏著，不爆雷），干擾選項把同一格材料換掉且不能是任何遊戲配方；跨元素比較題以「化學分類」分組且金屬／過渡金屬視為同組確保答案唯一、取材限已學元素；找碴題的錯誤元素強制「金屬類⇄非金屬類」跨界（或鈍氣）且不得構成另一條遊戲內配方，也不得換成遊戲外真實存在的反應（2026-09-29 窮舉補上，例：2B+3Cl₂→2BCl₃）；0-5 級分級熟練度（類 Leitner box，答錯只降級不歸零），難度自選＋每場勝利固定 +1 結晶、首次破關 +10、勝利結算畫面列出各元素熟練度；答錯立即顯示正解與一句解析；終極王國考鈾＋已背熟的⭐會考元素總複習
- 💎 **結晶經濟**：答題／合成／複習合成都能獲得結晶；偵探首次破案 +2（做了危險動作 +1）、配平首次完成 +1（看過答案不給）。消耗出口：戰鬥中花 3 顆排除兩個錯誤選項、合成台花 5 顆揭露一個配方材料

## 技術
- 純前端單檔 `index.html`，無建置流程，localStorage 存進度
- PWA：`manifest.json` + `sw.js`（離線快取）+ 安裝按鈕（ridgeline-branding skill 注入）
- 品牌識別：學習家族（第納利 Denali，`#4E6A7C`），六色盤主 UI；週期表分類色與王國代表色是功能性例外，非裝飾用品牌色

## 本機檢查
沒有 build 流程，但改動 `index.html` 裡的元素/王國/配方資料或出題邏輯後，建議跑：
```
node scripts/verify-game-data.js
```
會檢查：
- 資料：ELEMENTS/FULL_ELEMENTS/ZONES/RECIPES 的數量、符號重複、zone 對應、配方材料與組合
- 出題：實際呼叫 `nextBattleQuestion()` 模擬 2000 題，確認答案在選項內、選項不重複
- 找碴題：窮舉所有換法，不可換成真實存在的反應
- 反向合成：每條反應配方的產物化學式元素組成＝材料（答案唯一的前提）；模擬＋直接呼叫逐題確認剛好一個選項做得出產物、干擾選項不是遊戲配方、沒合成過的配方與合金不出題
- 三元合成門檻：二元不鎖、三元三種材料都達 `TRIPLE_MASTERY` 才可合成、合成過的熟練度掉回 0 仍可複習
- 研究室：部首（獨立字表）、各溫度下的物態（獨立判斷）、配平答案（窮舉 1～9 確認唯一最簡解）、偵探案件結構與焰色

研究室這段的規則都在腳本裡另寫一份，不引用 index.html 的實作，改動任何一邊都會互相抓到。
